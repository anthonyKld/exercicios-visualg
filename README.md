# 💻 Estudos de Lógica de Programação — VisualG

Este repositório foi criado para armazenar e organizar os algoritmos desenvolvidos durante meus estudos de **Lógica de Programação utilizando VisualG**.

O objetivo é acompanhar minha evolução na programação, praticando desde conceitos básicos até exercícios mais completos utilizando pseudocódigo.

## 📚 Conteúdos praticados

Ao longo do repositório serão adicionados exercícios envolvendo:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores aritméticos
* Operadores relacionais
* Operadores lógicos
* Estruturas condicionais
* `Se / Senão`
* `Escolha / Caso`
* Estruturas de repetição
* `Enquanto`
* `Repita`
* `Para`
* Contadores e acumuladores
* Cálculo de médias
* Maior e menor valor
* Validação de dados
* Vetores
* Matrizes
* Procedimentos
* Funções
* Outros exercícios de lógica de programação

## 🛠️ Tecnologia utilizada

Os algoritmos deste repositório são desenvolvidos utilizando:

**VisualG**

O VisualG utiliza uma linguagem baseada em **Portugol**, criada para auxiliar no aprendizado de lógica de programação e algoritmos.

Os arquivos possuem principalmente a extensão:

```text
.alg
```

## ▶️ Como executar os algoritmos

1. Instale ou abra o **VisualG**.
2. Faça o download ou clone este repositório.
3. Abra o arquivo `.alg` desejado no VisualG.
4. Execute o algoritmo utilizando o botão **Executar** ou pressione `F9`.

## 🎯 Objetivo do repositório

Este repositório funciona como um registro da minha evolução nos estudos de programação.

Além de armazenar os exercícios realizados durante as aulas, também serão adicionados códigos desenvolvidos para praticar e reforçar os conceitos aprendidos.

O repositório será atualizado conforme eu avançar nos estudos.
